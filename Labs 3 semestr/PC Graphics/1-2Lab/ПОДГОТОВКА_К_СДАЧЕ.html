Введение: Что такое HTML простыми словами?

Представь обычный текст. Если открыть его в браузере, браузер не знает, где заголовок, где кнопка, а где ссылка. HTML (HyperText Markup Language) — это язык разметки. Мы просто «наклеиваем ярлычки» (теги) на слова, чтобы браузер понял, как их показать.

Главное правило коробки:
Почти каждый тег открывается <тег> и обязательно закрывается со слэшем </тег>.
Пример: <b>Слово</b> — открыли тег жирного шрифта, написали слово, закрыли.

1. Скелет страницы (Каркас)

<!DOCTYPE html>
<html>
<head>
  <meta http-equiv=Content-Type content=text/html; charset=windows-1251>
  <title>Персональный сайт студента ИВТ - О себе</title>
</head>
<body bgcolor=#F4F7FB text=#1A202C link=#0056B3 vlink=#4A148C alink=#E53E3E>
  ...
</body>
</html>
  • <!DOCTYPE html> — кричит браузеру: «Рендери меня по современному стандарту HTML5, а не по правилам 90-х годов!».
  • <html> — самый главный контейнер всей страницы (корень документа).
  • <head> — невидимый «паспорт» страницы:
    • <title> — надпись на вкладке браузера вверху экрана.
    • <meta ... charset=windows-1251> — кодировка. Компьютер понимает буквы через номера байтов. Кодировка windows-1251 сопоставляет русские буквы байтам по стандарту Windows. Без неё русские буквы станут нечитаемыми «кракозябрами».
  • <body> — всё, что видит пользователь на экране. Атрибуты:
    • bgcolor=#F4F7FB — цвет фона страницы (мягкий серо-голубой оттенок). В хобби вместо него задан узор background=images/bg_pattern.svg.
    • text=#1A202C — цвет основного текста.
    • link=#0056B3 — цвет новых ссылок (синий).
    • vlink=#4A148C — цвет посещенных ссылок (фиолетовый).
    • alink=#E53E3E — цвет ссылки в момент нажатия (красный).

2. Как устроен дизайн (Белая карточка с рамкой)

Весь контент всех 6 страниц обёрнут в таблицу-контейнер:

<center>
  <table border=1 cellpadding=20 cellspacing=0 bgcolor=#FFFFFF bordercolor=#CBD5E0 width=88%>
    <tr>
      <td>
        ... весь текст и разделы ...
      </td>
    </tr>
  </table>
</center>
  • <center> — ставит карточку ровно по центру экрана.
  • width=88% — карточка занимает 88% экрана, оставляя по 6% красивых фоновых полей по бокам.
  • bgcolor=#FFFFFF — делает подложку ослепительно белой для четкого чтения.
  • border=1 bordercolor=#CBD5E0 — тонкая рамка мягкого светло-серого цвета.
  • cellpadding=20 — внутренний отступ в 20 пикселей между рамкой и текстом (чтобы текст не прилипал к краям).
  • cellspacing=0 — расстояние между ячейками равно нулю.

3. Навигация и внутренние ссылки

  • Сквозное меню: табличка <table border=0> вверху страницы. Текущая страница оформлена жирным без ссылки (<b>[ О себе ]</b>), остальные — ссылки на файлы: <a href=family.html>Моя семья</a>.
  • Ссылка «К началу страницы ↑» (якорь):
    • В самом верху страницы после <body> стоит скрытая метка-маяк: <a name=top></a>.
    • Внизу страницы ссылка со знаком решетки: <a href=#top>К началу страницы ↑</a>. Знак # говорит браузеру: «Ищи метку с именем top прямо на этой странице и прокрути экран вверх!».

5. Мнемоники («запрещенные» спецсимволы)

Символы <, >, &, " зарезервированы языком HTML. Если напечатать < прямо в тексте, браузер решит, что открылся новый тег, и сломает страницу. Поэтому пишут мнемоники:

  • &lt; — знак меньше (<);
  • &gt; — знак больше (>);
  • &quot; — двойная кавычка (");
  • &laquo; и &raquo; — кавычки-ёлочки (« и »);
  • &mdash; — длинное тире (—);
  • &bull; — круглый маркер списка (•);
  • &uarr; — стрелка вверх в ссылке наверх (↑).
